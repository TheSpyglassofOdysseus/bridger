# Support

Bridger is an open-source infrastructure project. There is no guaranteed support SLA.

## Before opening an issue

Please:

1. read `START_HERE.md`, `SECURITY.md`, and the relevant guide;
2. run `scripts/preflight-starter.sh` and the appropriate check script;
3. remove secrets, tokens, private hostnames/IPs, and personal data from logs/screenshots;
4. search existing issues for the same problem.

## Good bug reports include

- operating system and architecture;
- Python, Node, and npm versions;
- exact Bridger commit/release;
- which deployment path you are using;
- expected vs actual behavior;
- minimal sanitized logs or reproduction steps.

## Security issues

Do **not** open a public issue for a vulnerability, credential exposure, or exploit details. Follow `SECURITY.md`.

## Scope

Questions about Oracle, Tailscale, Cloudflare, GitHub, ChatGPT, Claude, or another client/provider may depend on those providers' current products and terms. Use their current official documentation for account-specific or rapidly changing setup steps.
