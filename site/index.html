The easy path

Five steps. No infrastructure degree required.

For ChatGPT, the private path is: your server + Bridger MCP + OpenAI Secure MCP Tunnel + your own plugin connection.

Before step 1: check compatibility

ChatGPT’s full write-capable MCP support is currently available to Business and Enterprise/Edu workspaces; Pro currently supports read/fetch MCP only. If your ChatGPT setup does not support the connection you need, find that out before provisioning a server. Check current OpenAI support ↗

01

Get a server

Use eligible Oracle free ARM compute when available, or another ARM64 Linux server you control.

02

Run the installer

One script installs Bridger, its private Node runtime, Tailscale, credentials, services, and health checks.

03

Create a tunnel

The tunnel wizard uses OpenAI’s official client so Bridger stays private with no inbound MCP port.

04

Add the plugin

In ChatGPT Plugins, choose Tunnel and select the tunnel you created in your own OpenAI account.

05

Build & explore

Your AI can now help inspect, build, deploy, and maintain projects on the server that stays on.

What you don't need

Start without buying a pile of hardware or services.

—

No Mac mini

You do not need dedicated hardware or an always-on desktop at home. The server can live in the cloud.

—

No paid VPS required

The reference path targets Oracle's free ARM compute when your account is eligible and capacity is available.

—

No domain required

Tailscale is enough for private access. Free DNS or a free subdomain can be used when you want a shareable name.

—

No shared AI account

Bridger does not use the author's API keys, credits, or usage. You bring your own AI account or client.

Bridger can help move persistent work onto your own server, which may reduce how often you need expensive or limited agent modes. It does not bypass your AI provider's access rules, usage limits, or billing.
