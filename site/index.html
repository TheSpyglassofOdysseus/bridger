The path

From “I use AI” to “I own the machine.”

01

Get compute

Provision a small Linux VM. Oracle is the reference path; the design is not locked to Oracle.

02

Make it private

Put administration and private apps on Tailscale before you think about exposing anything publicly.

03

Connect Bridger

Give your AI a bounded, auditable way to inspect files, run commands, and operate services.

04

Build whatever

Sites, dashboards, research tools, automations, APIs, games—now the machine persists after the chat ends.

Reference stack
Oracle Cloud

Reference compute path. Use the console or OCI CLI when capacity/provisioning demands it; verify your own account entitlements.

Tailscale

Private device-to-server network for administration, previews, dashboards, and internal services.

Cloudflare

Optional domain, DNS, and public web edge when you deliberately want something on the Internet.

GitHub

Source, history, collaboration, releases, and recovery. Useful, but not something you need to understand before starting.

Bridger

The controlled execution boundary that gives an authorized AI practical hands on the Linux host.
