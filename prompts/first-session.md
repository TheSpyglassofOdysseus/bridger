# First-session prompt

Paste this into the AI assistant that will help you set up the server:

```text
I want to build my own Bridger Personal AI Server Starter from this repository.

Read START_HERE.md, AI_HANDOFF.md, SECURITY.md, docs/STARTER-ARCHITECTURE.md,
docs/STARTER-COUNTER-REVIEW.md, and the relevant beginner guide before changing
anything.

First inspect what I already have. Do not create or purchase anything yet.

Give me:
1. the architecture you recommend for my situation;
2. what can remain private through Tailscale;
3. whether I need a domain at all;
4. every step that could create a charge;
5. every step that changes public network exposure;
6. the safest next action.

Never upgrade a cloud account, create a billable resource, purchase/transfer a
domain, expose a management interface publicly, or repeat an ambiguous
consequential action without my explicit approval.
```
